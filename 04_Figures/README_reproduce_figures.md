# Recreating Figure 1

Run from the repository root after installing the optional plotting dependency:

```bash
python -m pip install -r 04_Figures/requirements-figures.txt
python 04_Figures/reproduce_fig1_from_aggregate.py
```

The script reads `03_Results/paper_results_kbs_aggregate.csv` and writes a PNG and PDF under `04_Figures/reproduced_from_aggregate/`. The panel (b) means and standard deviations are rounded in the public aggregate table, so the recreated plot may differ slightly from the original rendered image. It is not a seed-level reconstruction. Panel (a) is an explicitly illustrative asymptotic scaling diagram.

The current KBS figure assets remain the files directly under `04_Figures/`. The other four figures are included as manuscript assets but are not regenerated by this script.
