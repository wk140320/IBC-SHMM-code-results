# Aggregated results

`paper_results_kbs_aggregate.csv` contains 312 KBS-related rows selected from the v7 authoritative result matrix. Selection retained the `Shared_Main_And_K1`, `Shared_Main_And_D04`, `KBS_K4_Calibration`, and `KBS_Schur_Mechanism` domains. It excludes Neurocomputing-only results and records explicitly tied to an individual subject; it also drops the internal source-file path column. No participant-level or event-level rows are included.

Source matrix: `paper_results_final.csv` from the KBS v7 evidence package, SHA-256 before filtering: `6ac0261fa94225ee89241cf18a279b4dc3708895f4c76fab98bf368c989ea9ba`. This public table is an aggregate export and should be interpreted alongside the post-hoc/exploratory amendment in `00_Protocol/`.
